ClipSave

공개 영상과 재생목록을 Mac과 Windows에서 MP4 또는 MP3로 저장하세요. 링크를 붙여넣고 형식을 고르면 진행 상황과 완료 파일을 한 화면에서 확인할 수 있습니다.

macOS용 다운로드 Windows용 다운로드

버전 1.4.0 · Apple Silicon macOS · Windows x64

다운로드가 쉬워지는 방식

복잡한 로그 대신, 누구나 이해할 수 있는 진행 화면.

대기 중, 진행 중, 완료 상태를 카드와 진행 막대로 보여줍니다. 다운로드가 끝나면 완료 목록으로 자동 정리됩니다.

macOS

Mac에서 바로 실행

Apple Silicon Mac용 zip 파일입니다. 압축을 풀고 앱 아이콘을 열면 바로 사용할 수 있습니다.

ClipSave-1.4.0-mac-arm64.zip

Windows

Windows에서도 동일하게

Windows x64용 zip 파일입니다. Node.js, yt-dlp, ffmpeg를 따로 설치하지 않아도 됩니다.

ClipSave-1.4.0-win-x64.zip

핵심 기능

로컬에서 조용하게, 결과물은 깔끔하게.

01

MP4와 MP3

영상 전체 저장 또는 MP3 오디오 추출을 선택할 수 있습니다.

02

재생목록

단일 영상뿐 아니라 공개 재생목록도 순서대로 처리합니다.

03

화질 선택

최고 가능 화질, 1080p, 720p, 480p 등 원하는 품질을 고를 수 있습니다.

04

중간 파일 정리

완료 후에는 최종 MP3 또는 MP4 파일만 남도록 정리합니다.

라이선스

개인 사용은 가능하지만, 재사용과 상업적 이용은 허가가 필요합니다.

ClipSave는 소스 공개 프로젝트입니다. 개인적, 비상업적 사용은 허용되지만 제작자의 사전 서면 허가 없이 재사용, 재배포, 수정, 상업적 이용을 할 수 없습니다.

허가 없는 상업적 이용은 관련 법률에 따라 법적 책임이 발생할 수 있습니다.
