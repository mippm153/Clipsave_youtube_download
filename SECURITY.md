# Security Policy

## Supported Versions

The latest GitHub Release is the supported version.

## Reporting a Vulnerability

Please open a private security advisory on GitHub or contact the repository owner directly.

Do not file public issues for vulnerabilities that expose users to unsafe downloads, command execution, or malicious media handling.

## Scope

ClipSave is a local desktop app. It should not bypass DRM, paid access, private content, or login-protected media.
